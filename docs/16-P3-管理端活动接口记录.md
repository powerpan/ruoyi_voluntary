## 3. 接口清单

接口前缀：`/manager/voluntary/activities`

| 方法 | 路径 | 功能 | 权限 |
| --- | --- | --- | --- |
| `GET` | `/list` | 活动分页列表 | `manager:voluntary:activity:list` |
| `GET` | `/{id}` | 活动详情 | `manager:voluntary:activity:query` |
| `POST` | 空路径 | 新增活动草稿 | `manager:voluntary:activity:add` |
| `PUT` | `/{id}` | 编辑草稿或已下架活动 | `manager:voluntary:activity:edit` |
| `PUT` | `/{id}/status` | 发布、下架、结束、取消活动 | `manager:voluntary:activity:edit` |

新增、编辑和状态变更接口均已添加 `@Log` 操作日志。

## 4. 服务层规则

### 4.1 活动字段校验

新增和编辑活动时，服务层校验：

1. 活动标题不能为空。
2. 活动类型不能为空。
3. 服务地点不能为空。
4. 活动开始时间和结束时间不能为空。
5. 活动开始时间必须早于结束时间。
6. 报名开始时间和截止时间不能为空。
7. 报名开始时间必须早于截止时间。
8. 报名截止时间不能晚于活动开始时间。
9. 招募人数必须大于 0。
10. 最大可计入服务分钟数如填写，必须大于 0。

### 4.2 新增规则

新增活动固定进入草稿状态：

```text
status = 0
approvedCount = 0
createBy = 当前管理员
createTime = 当前时间
```

状态发布必须通过状态变更接口完成，避免新增接口绕过发布校验。

### 4.3 编辑规则

当前只允许编辑：

1. 草稿活动。
2. 已下架活动。

已发布、已结束、已取消活动不能通过编辑接口直接修改核心信息。

### 4.4 状态流转规则

当前支持：

| 当前状态 | 目标状态 | 说明 |
| --- | --- | --- |
| 草稿 | 已发布 | 发布前执行完整字段校验 |
| 草稿 | 已取消 | 取消未发布活动 |
| 已发布 | 已下架 | 暂停公开展示 |
| 已发布 | 已结束 | 手动结束活动 |
| 已发布 | 已取消 | 取消已发布活动 |
| 已下架 | 已发布 | 重新发布 |
| 已下架 | 已取消 | 取消已下架活动 |

已结束和已取消活动作为终态，不能继续变更状态。

### 5.2 运行级接口冒烟


验证接口：

| --- | --- | --- |

| 2 | `POST /manager/voluntary/activities` | 创建草稿活动成功，返回 `status=0` |

| 6 | `PUT /manager/voluntary/activities/{id}/status`，`status=1` | 发布成功，返回 `status=1` 和 `publishTime` |
| 7 | `PUT /manager/voluntary/activities/{id}/status`，`status=3` | 下架成功，返回 `status=3` |
| 8 | `PUT /manager/voluntary/activities/{id}/status`，`status=1` | 已下架活动重新发布成功 |
