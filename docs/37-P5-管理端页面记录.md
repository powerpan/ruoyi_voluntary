## 2. 管理端统计页面

新增文件：

| 文件 | 说明 |
| --- | --- |
| `ruoyi-ui/src/api/voluntary/statistics.js` | 统计接口封装 |
| `ruoyi-ui/src/views/voluntary/statistics/index.vue` | 数据统计页面 |

页面路径沿用 P5-A 菜单配置：

| 菜单 | 路径 | 组件 |
| --- | --- | --- |
| 数据统计 | `/voluntary/statistics` | `voluntary/statistics/index` |

接入接口：

| 接口 | 页面区域 |
| --- | --- |
| `GET /manager/voluntary/statistics/overview` | 顶部统计总览 |
| `GET /manager/voluntary/statistics/activities` | 活动统计表 |
| `GET /manager/voluntary/statistics/volunteers` | 志愿者排行表 |
| `GET /manager/voluntary/statistics/organizations` | 组织统计表 |
| `GET /manager/voluntary/statistics/trend` | 服务趋势图和趋势表 |

页面能力：

1. 支持按统计日期、活动标题、组织、志愿者姓名筛选。
2. 趋势支持按日和按月切换。
3. 顶部展示志愿者、活动、报名、签到签退、有效服务记录和异常记录。
4. 使用现有 `echarts` 依赖渲染服务趋势折线图，不新增前端依赖。

## 3. 管理端通知记录页面

新增文件：

| 文件 | 说明 |
| --- | --- |
| `ruoyi-ui/src/api/voluntary/notification.js` | 通知接口封装 |
| `ruoyi-ui/src/views/voluntary/notification/index.vue` | 通知记录页面 |

页面路径沿用 P5-A 菜单配置：

| 菜单 | 路径 | 组件 |
| --- | --- | --- |
| 通知记录 | `/voluntary/notification` | `voluntary/notification/index` |

接入接口：

| 接口 | 页面区域 |
| --- | --- |
| `GET /manager/voluntary/notifications/list` | 通知记录分页表 |
| `GET /manager/voluntary/notifications/{id}` | 通知详情弹窗 |

页面能力：

1. 支持按接收人、标题、通知类型、阅读状态、业务对象、创建时间筛选。
2. 列表展示标题、内容摘要、接收人、通知类型、阅读状态、业务对象、创建时间和阅读时间。
3. 详情弹窗展示通知内容、触发人、跳转地址和备注。
4. 通知类型使用 `vol_notification_type` 字典，阅读状态使用 `vol_notification_status` 字典。

## 4. 导出按钮接入

四个已有管理端页面新增导出按钮，均复用 RuoYi 前端全局 `download()` 方法，并保留当前筛选条件。

| 页面 | 文件 | 导出接口 | 权限 |
| --- | --- | --- | --- |
| 志愿者审核 | `ruoyi-ui/src/views/voluntary/volunteer/index.vue` | `POST /manager/voluntary/volunteers/export` | `manager:voluntary:volunteer:export` |
| 报名管理 | `ruoyi-ui/src/views/voluntary/signup/index.vue` | `POST /manager/voluntary/signups/export` | `manager:voluntary:signup:export` |
| 签到管理 | `ruoyi-ui/src/views/voluntary/checkin/index.vue` | `POST /manager/voluntary/checkins/export` | `manager:voluntary:checkin:export` |
| 服务记录 | `ruoyi-ui/src/views/voluntary/serviceRecord/index.vue` | `POST /manager/voluntary/service-records/export` | `manager:voluntary:serviceRecord:export` |

签到管理和服务记录页面的导出参数已复用页面日期范围，保持与列表查询口径一致。

导出接口本身已在 P5-E 完成后端编译和导出字段单元测试验证。后续 P5-H 总验收时，可使用普通浏览器手动点击四个导出按钮，确认 Excel 文件下载。
