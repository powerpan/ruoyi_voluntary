# P4-A 数据库骨架记录

## 1. 本阶段目标

P4-A 的目标是只完成二维码签到签退与服务记录的数据库骨架，不提前实现接口、Service 或页面。

本次新增内容：

1. `vol_activity_qr_token`：活动签到签退二维码令牌表。
2. `vol_checkin_record`：签到签退原始记录表。
3. `vol_service_record`：最终计入统计的服务记录表。
4. `vol_qr_token_status`：二维码令牌状态字典。
5. `vol_checkin_status`：签到签退记录状态字典。
6. `vol_service_record_status`：服务记录状态字典。
7. 管理端“签到管理”和“服务记录”菜单及按钮权限。
8. `voluntary_admin` 角色绑定 P4-A 菜单权限。

## 3. 表结构摘要

### 3.1 `vol_activity_qr_token`

用途：保存管理端生成的签到和签退二维码令牌。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `activity_id` | 关联活动 |
| `token` | 二维码随机令牌 |
| `action_type` | `checkin` 或 `checkout` |
| `expire_time` | 过期时间 |
| `status` | `0有效 1失效` |

索引：

1. `uk_qr_token(token)`
2. `idx_qr_activity_action(activity_id, action_type, status, expire_time)`

### 3.2 `vol_checkin_record`

用途：保存志愿者参与活动的签到和签退原始记录。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `activity_id` | 活动 ID |
| `signup_id` | 报名 ID |
| `volunteer_user_id` | 志愿者用户 ID |
| `checkin_time` | 签到时间 |
| `checkout_time` | 签退时间 |
| `status` | `0已签到 1已签退 2异常 3人工确认` |

索引：

1. `uk_checkin_activity_user(activity_id, volunteer_user_id)`
2. `idx_checkin_activity_status(activity_id, status, checkin_time)`
3. `idx_checkin_user(volunteer_user_id, checkin_time)`

### 3.3 `vol_service_record`

用途：保存最终计入志愿服务时长统计的服务记录。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `activity_id` | 活动 ID |
| `signup_id` | 报名 ID |
| `checkin_record_id` | 签到签退记录 ID |
| `volunteer_user_id` | 志愿者用户 ID |
| `service_date` | 服务日期 |
| `start_time` | 计入开始时间 |
| `end_time` | 计入结束时间 |
| `service_minutes` | 计入服务分钟数 |
| `status` | `0待确认 1有效 2异常 3作废` |

索引：

1. `uk_service_checkin(checkin_record_id)`
2. `idx_service_user_date(volunteer_user_id, service_date)`
3. `idx_service_activity(activity_id, status)`
4. `idx_service_status(status, service_date)`
