# P4-C 管理端二维码接口记录

## 1. 本阶段目标

P4-C 的目标是完成管理端活动二维码令牌接口，为后续用户端扫码签到签退提供入口数据。

本阶段只实现管理端 token 生成、查询和停用，不提前实现：

1. 用户端扫码签到。
2. 用户端扫码签退。
3. 签退后自动生成服务记录。
4. 管理端签到记录页面。
5. 统计图表、通知中心或导出。

## 3. 接口清单

### 3.1 查询活动二维码令牌

```http
GET /manager/voluntary/activities/{activityId}/qr-tokens
```

权限：

```text
manager:voluntary:checkin:qr
```

支持分页参数：

| 参数 | 说明 |
| --- | --- |
| `pageNum` | 页码 |
| `pageSize` | 每页条数 |
| `actionType` | `checkin` 或 `checkout` |
| `status` | `0有效 1失效` |

返回字段包含：

1. 活动 ID。
2. token。
3. actionType。
4. expireTime。
5. status。
6. 活动标题。
7. 服务地点。
8. scanUrl。

### 3.2 生成签到或签退二维码令牌

```http
POST /manager/voluntary/activities/{activityId}/qr-tokens
```

权限：

```text
manager:voluntary:checkin:qr
```

请求体：

```json
{
  "actionType": "checkin",
  "expireMinutes": 60
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `actionType` | `checkin` 表示签到，`checkout` 表示签退 |
| `expireMinutes` | token 有效分钟数；为空默认 120，最大 1440 |

返回：新生成的二维码令牌和扫码地址。

### 3.3 停用二维码令牌

```http
PUT /manager/voluntary/qr-tokens/{id}/disable
```

权限：

```text
manager:voluntary:checkin:qr
```

返回：停用后的二维码令牌。

## 4. 业务规则

### 4.1 生成规则

1. 活动 ID 不能为空。
2. 活动必须存在。
3. 只有已发布活动可以生成二维码。
4. `actionType` 只允许 `checkin` 和 `checkout`。
5. `expireMinutes` 必须大于 0，且不能超过 1440。
6. 生成同一活动同一操作类型的新 token 前，会先将旧有效 token 置为失效。
7. token 使用 RuoYi `IdUtils.fastSimpleUUID()` 生成，不在二维码中暴露活动 ID 或用户 ID。

### 4.2 返回扫码地址

扫码地址由配置项控制：

```yaml
voluntary:
  scan-url-prefix: "${RUOYI_VOLUNTARY_SCAN_URL_PREFIX:http://localhost:8088/#/scan?token=}"
```

接口返回时会拼接：

```text
scanUrl = scan-url-prefix + token
```

当前本地默认格式：

```text
http://localhost:8088/#/scan?token=<token>
```

### 4.3 停用规则

1. token ID 不能为空。
2. token 必须存在。
3. 已失效 token 重复停用时直接返回当前记录。
4. 有效 token 停用后状态变为 `1`。

### 5.3 接口冒烟

验证命令摘要：

```bash
curl -s -X POST http://127.0.0.1:8080/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin123"}'

curl -s -X POST http://127.0.0.1:8080/manager/voluntary/activities/2/qr-tokens \
  -H "Authorization: Bearer <token>" \
  -H 'Content-Type: application/json' \
  -d '{"actionType":"checkin","expireMinutes":60}'

curl -s -X POST http://127.0.0.1:8080/manager/voluntary/activities/2/qr-tokens \
  -H "Authorization: Bearer <token>" \
  -H 'Content-Type: application/json' \
  -d '{"actionType":"checkout","expireMinutes":60}'

curl -s -X POST http://127.0.0.1:8080/manager/voluntary/activities/2/qr-tokens \
  -H "Authorization: Bearer <token>" \
  -H 'Content-Type: application/json' \
  -d '{"actionType":"checkin","expireMinutes":30}'

curl -s -X PUT http://127.0.0.1:8080/manager/voluntary/qr-tokens/3/disable \
  -H "Authorization: Bearer <token>"
```

验证结果：

| 场景 | 结果 |
| --- | --- |
| 管理员登录 | 返回 `code=200` 和 token |
| 生成签到 token | 返回 `code=200`，`actionType=checkin`，`status=0` |
| 生成签退 token | 返回 `code=200`，`actionType=checkout`，`status=0` |
| 查询活动 token | 返回分页数据和 `scanUrl` |
| 重复生成签到 token | 新签到 token 为有效，旧签到 token 自动置为失效 |
| 停用 token | 返回 `status=1` |
| 非法 `actionType` | 返回 `二维码操作类型只能为签到或签退` |
| 未发布活动生成 token | 返回 `只有已发布活动可以生成二维码` |
| 不存在活动生成 token | 返回 `活动不存在` |
