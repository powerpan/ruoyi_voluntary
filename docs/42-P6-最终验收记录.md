## 4. SQL 初始化验收

当前命令行环境无法通过 TCP 或 Unix socket 连接本机 MySQL，因此使用 phpStudy 自带 MySQL 5.7.28 的 `mysqld --bootstrap` 对 SQL 脚本做离线导入校验。

验证方式：

1. 在 `/private/tmp` 初始化独立临时 MySQL datadir。
2. 使用 `mysqld --bootstrap` 分别导入 `sql/ruoyi_voluntary.sql` 和 `sql/ruoyi_voluntary_minimal.sql`。
3. 检查退出码、生成表数量和关键业务表文件。
4. 删除 bootstrap 临时 datadir。

执行结果：

| 脚本 | bootstrap 退出码 | 生成表数量 | 核心业务表 |
| --- | --- | --- | --- |
| `sql/ruoyi_voluntary.sql` | 0 | 28 | 全部存在 |
| `sql/ruoyi_voluntary_minimal.sql` | 0 | 28 | 全部存在 |

已确认核心表：

1. `sys_user`
2. `sys_role`
3. `sys_menu`
4. `vol_volunteer_profile`
5. `vol_audit_record`
6. `vol_activity`

## 8. 演示建议

演示时建议按以下顺序：

1. 管理端登录，展示志愿管理菜单。
2. 用户端注册或使用已有志愿者账号进入个人中心。
3. 管理端审核志愿者。
4. 管理端创建并发布活动。
5. 用户端浏览活动并报名。
6. 管理端筛选通过报名。
7. 管理端生成签到/签退二维码。
8. 用户端扫码签到、扫码签退。
9. 用户端查看服务记录和累计时长。
10. 管理端查看统计、通知记录并导出 Excel。

## 9. 已知限制

以下内容不作为当前课程项目必做范围：

1. 第三方短信、邮件或微信推送。
2. 组织管理员数据权限隔离。
3. 服务证明 PDF 自动生成。
4. 地图定位签到。
5. 高并发压测和线上监控体系。

这些内容已在论文支撑材料中列入后续展望，不在当前验收中冒充已实现能力。
