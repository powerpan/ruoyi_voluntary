## 3. 新增通知表

表名：`vol_notification`

| 字段 | 说明 |
| --- | --- |
| `id` | 通知 ID |
| `receiver_user_id` | 接收人用户 ID |
| `actor_user_id` | 触发人用户 ID，可为空 |
| `notice_type` | 通知类型 |
| `target_type` | 业务对象类型 |
| `target_id` | 业务对象 ID |
| `title` | 通知标题 |
| `content` | 通知内容 |
| `action_url` | 用户端跳转地址 |
| `status` | 阅读状态，`0` 未读，`1` 已读 |
| `read_time` | 阅读时间 |
| `create_by`、`create_time`、`update_by`、`update_time`、`remark` | RuoYi 通用审计字段 |

索引：

| 索引 | 字段 | 用途 |
| --- | --- | --- |
| `PRIMARY` | `id` | 主键 |
| `idx_notification_receiver_status` | `receiver_user_id,status,create_time` | 用户端“我的通知”和未读筛选 |
| `idx_notification_target` | `target_type,target_id` | 按业务对象追溯通知 |
| `idx_notification_type` | `notice_type,create_time` | 管理端按通知类型查询 |
