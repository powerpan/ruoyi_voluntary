# P2 用户端个人中心页面记录

## 1. 本次目标

本次推进范围是 P2-F 的用户端部分：将用户端 `/me` 个人中心页面接入已完成的 `/app/voluntary/profile` 档案接口。

本次完成后，登录后的志愿者可以在页面上：

1. 查看自己的审核状态。
2. 查看累计服务时长和有效服务次数。
3. 查看并维护实名资料、联系方式、组织、班级、服务特长和紧急联系人。
4. 在资料保存成功后看到页面状态同步更新。

本次不做管理端志愿者审核页面，也不做活动报名权限拦截。

## 2. 前端改动

新增 API 封装：

```text
voluntary-app/src/api/voluntary/profile.js
```

包含方法：

| 方法 | 接口 | 说明 |
| --- | --- | --- |
| `getVolunteerProfile` | `GET /app/voluntary/profile` | 查询当前登录用户档案 |
| `updateVolunteerProfile` | `PUT /app/voluntary/profile` | 保存当前登录用户档案 |
| `getVolunteerAuditStatus` | `GET /app/voluntary/profile/audit-status` | 查询审核状态，供后续首页或报名入口复用 |

改造页面：

```text
voluntary-app/src/views/Me.vue
```

页面能力：

1. 顶部显示志愿者姓名、账号、手机号、组织和审核状态。
2. 统计区显示累计服务小时数、有效服务次数和档案审核状态。
3. 表单维护字段与后端 `VolVolunteerProfile` 可维护字段一致。
4. 禁用状态下前端禁用资料编辑。
5. 保存成功后使用后端返回的最新档案刷新页面。

## 3. 页面状态规则

| 审核状态 | 页面展示 | 资料编辑 |
| --- | --- | --- |
| `0 待审核` | 黄色标签和待审核提示 | 允许修改 |
| `1 已通过` | 绿色标签和通过提示 | 允许修改；后端会按关键字段变更规则决定是否回到待审核 |
| `2 已驳回` | 红色标签和驳回提示，展示审核意见 | 允许修改并重新提交 |
| `3 已禁用` | 灰色标签和禁用提示 | 不允许修改 |

## 4. 表单校验

用户端页面加入了基础校验：

| 字段 | 校验 |
| --- | --- |
| `realName` | 必填 |
| `gender` | 必选 |
| `idCard` | 必填，支持 15 位或 18 位身份证格式 |
| `phone` | 必填，手机号格式 |
| `emergencyPhone` | 非必填，填写时校验手机号格式 |

更严格的业务规则仍以后端为准，前端只做基础交互校验。
