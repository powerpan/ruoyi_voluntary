# P4-D 用户端扫码接口记录

## 1. 本阶段目标

P4-D 的目标是补齐志愿者端二维码扫码接口，使已登录志愿者可以根据管理端生成的 token 查询扫码状态，并完成二维码签到和签退。

本阶段只实现接口层和签到签退原始记录，不提前实现：

1. 签退后自动生成服务记录。
2. 志愿者累计服务时长和服务次数更新。
3. 用户端扫码结果页、服务记录页。
4. 管理端签到记录页、服务记录页。
5. 统计图表、通知中心或导出。

服务记录生成和累计时长维护进入 P4-E；页面接入进入 P4-F/P4-G；完整时间窗口规则在 P4 闭环验收前统一收口。

## 3. 接口清单

### 3.1 查询扫码信息

```http
GET /app/voluntary/scan/{token}
```

登录：需要。

返回内容：

| 字段 | 说明 |
| --- | --- |
| `qrToken` | 二维码 token、操作类型、活动标题、服务地点、过期时间 |
| `activity` | 活动基础信息 |
| `signup` | 当前用户在该活动下的报名记录 |
| `checkinRecord` | 当前用户在该活动下的签到签退记录 |
| `actionable` | 当前是否可以执行该 token 对应动作 |
| `message` | 当前扫码状态提示 |

### 3.2 二维码签到

```http
POST /app/voluntary/scan/{token}/checkin
```

登录：需要。

成功后写入 `vol_checkin_record`：

| 字段 | 值 |
| --- | --- |
| `checkin_time` | 当前时间 |
| `checkin_method` | `qr` |
| `status` | `0`，已签到 |
| `create_by` | 当前用户名 |
| `create_time` | 当前时间 |
| `remark` | `二维码签到` |

### 3.3 二维码签退

```http
POST /app/voluntary/scan/{token}/checkout
```

登录：需要。

成功后更新 `vol_checkin_record`：

| 字段 | 值 |
| --- | --- |
| `checkout_time` | 当前时间 |
| `checkout_method` | `qr` |
| `status` | `1`，已签退 |
| `update_by` | 当前用户名 |
| `update_time` | 当前时间 |
| `remark` | `二维码签退` |

## 4. 业务规则

### 4.1 通用校验

1. token 不能为空。
2. 当前用户必须登录。
3. token 必须存在、状态有效且未过期。
4. token 关联活动必须存在。
5. 活动状态必须为已发布。
6. 当前用户在该活动下的报名记录会随扫码信息一起返回。

### 4.2 签到校验

1. token 的 `action_type` 必须为 `checkin`。
2. 当前用户必须已报名该活动。
3. 报名状态必须为 `1`，即已通过筛选。
4. 同一活动同一志愿者不能重复签到。
5. 已签退记录不能再次签到。

### 4.3 签退校验

1. token 的 `action_type` 必须为 `checkout`。
2. 当前用户必须已报名该活动且报名通过。
3. 当前用户必须已经完成签到。
4. 只有 `status=0` 的已签到记录可以签退。
5. 已签退记录不能重复签退。

### 5.3 接口冒烟

临时写入 3 条二维码 token：

| token | 活动 | 类型 | 用途 |
| --- | --- | --- | --- |
| `p4d_checkin_token` | `id=2` | `checkin` | 正常签到 |
| `p4d_checkout_token` | `id=2` | `checkout` | 正常签退 |
| `p4d_pending_token` | `id=1` | `checkin` | 报名未通过拦截 |

验证结果：

| 场景 | 结果 |
| --- | --- |
| 查询签到 token | 返回 `code=200`，`actionable=true`，`message=可以签到` |
| 未签到直接签退 | 返回 `尚未签到，不能签退` |
| 正常签到 | 返回 `code=200`，`status=0`，`checkinTime` 和 `createTime` 均有值 |
| 重复签到 | 返回 `已完成签到，不能重复签到` |
| 查询签退 token | 返回 `code=200`，`actionable=true`，`message=可以签退` |
| 正常签退 | 返回 `code=200`，`status=1`，`checkoutTime` 和 `updateTime` 均有值 |
| 重复签退 | 返回 `已完成签退，不能重复签退` |
| 报名待筛选扫码 | 返回 `code=200`，`actionable=false`，`message=报名未通过，不能扫码签到签退` |
| 报名待筛选强制签到 | 返回 `报名未通过，不能扫码签到签退` |

数据库落点：

```text
vol_checkin_record:
id=1
activity_id=2
signup_id=2
volunteer_user_id=2
checkin_time=2026-05-25 09:10:31
checkout_time=2026-05-25 09:10:59
checkin_method=qr
checkout_method=qr
status=1
create_time=2026-05-25 09:10:31
update_time=2026-05-25 09:10:59

vol_service_record: 0
```

`vol_service_record` 未生成记录是符合 P4-D 边界的，服务记录生成在 P4-E 实现。
