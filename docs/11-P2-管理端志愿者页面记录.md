# P2 管理端志愿者页面记录

## 1. 本次目标

本次推进范围是 P2-F 的管理端部分：把 P2-E 已完成的志愿者审核接口接入管理端页面，并初始化菜单和按钮权限。

本次完成后，管理员可以在后台页面完成：

1. 按账号、姓名、手机号、组织和审核状态筛选志愿者。
2. 查看志愿者档案列表和审核状态。
3. 查看志愿者档案详情。
4. 编辑志愿者实名档案。
5. 审核通过、驳回、禁用和启用志愿者。
6. 查看志愿者审核记录。

本次不做用户端首页审核提示，也不做 P3 活动报名权限拦截。

## 2. 前端改动

新增管理端 API 封装：

```text
ruoyi-ui/src/api/voluntary/volunteer.js
```

封装接口：

| 方法 | 后端接口 | 前端函数 |
| --- | --- | --- |
| `GET` | `/manager/voluntary/volunteers/list` | `listVolunteer` |
| `GET` | `/manager/voluntary/volunteers/{id}` | `getVolunteer` |
| `PUT` | `/manager/voluntary/volunteers/{id}` | `updateVolunteer` |
| `POST` | `/manager/voluntary/volunteers/{id}/audit` | `auditVolunteer` |
| `PUT` | `/manager/voluntary/volunteers/{id}/status` | `changeVolunteerStatus` |
| `GET` | `/manager/voluntary/volunteers/{id}/audit-records` | `listVolunteerAuditRecords` |

新增管理端页面：

```text
ruoyi-ui/src/views/voluntary/volunteer/index.vue
```

页面能力：

1. 查询表单：账号、姓名、手机号、组织、审核状态。
2. 表格字段：账号、姓名、性别、手机号、组织、审核状态、账号状态、服务时长、服务次数、创建时间。
3. 行操作：详情、编辑、审核通过、驳回、禁用、启用、审核记录。
4. 弹窗：档案编辑、审核处理、详情查看、审核记录查看。
5. 权限：页面按钮使用 `v-hasPermi` 控制。

同步更新后台首页：

```text
ruoyi-ui/src/views/index.vue
```

首页文案已从 P1 骨架阶段调整为 P2 志愿者账号与档案阶段，避免后台首页仍提示业务菜单未开放。
