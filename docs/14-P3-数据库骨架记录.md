本次推进范围是 P3-A：先落地活动与报名的数据库骨架、状态字典和管理端菜单权限。

## 3. 新增活动表

表名：`vol_activity`

用途：保存志愿活动基础信息、报名配置、发布状态和后续统计缓存。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `title` | 活动标题 |
| `activity_type` | 活动类型，复用 `vol_activity_type` |
| `service_location` | 服务地点 |
| `start_time`、`end_time` | 活动开始和结束时间 |
| `signup_start_time`、`signup_end_time` | 报名开始和截止时间 |
| `recruit_count` | 招募人数 |
| `approved_count` | 已通过报名人数 |
| `content` | 活动内容 |
| `requirements` | 报名要求 |
| `manager_name`、`manager_phone` | 活动负责人和联系电话 |
| `max_service_minutes` | P4 计算服务时长时使用的上限 |
| `status` | 活动状态 |
| `publish_time` | 发布时间 |

索引：

```text
PRIMARY KEY (`id`)
idx_activity_public(status, start_time, activity_type)
idx_activity_signup_time(signup_start_time, signup_end_time)
idx_activity_title(title)
```

## 4. 新增报名表

表名：`vol_activity_signup`

用途：保存志愿者报名申请和管理员筛选结果。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `activity_id` | 活动 ID |
| `volunteer_user_id` | 志愿者用户 ID |
| `real_name`、`phone`、`organization` | 报名时的志愿者资料快照 |
| `apply_reason` | 报名理由 |
| `experience` | 相关经验 |
| `status` | 报名状态 |
| `review_reason` | 筛选意见 |
| `reviewer_id`、`reviewer_name` | 处理人 |
| `review_time` | 处理时间 |

索引：

```text
PRIMARY KEY (`id`)
uk_signup_activity_user(activity_id, volunteer_user_id)
idx_signup_activity_status(activity_id, status, create_time)
idx_signup_user_status(volunteer_user_id, status, create_time)
```

`uk_signup_activity_user` 用于防止同一志愿者重复报名同一活动。后续服务层如果允许取消后再次报名，应更新原报名记录，而不是插入重复数据。

## 5. 新增字典

### 5.1 活动状态

字典类型：`vol_activity_status`

| 值 | 标签 | 用途 |
| --- | --- | --- |
| `0` | 草稿 | 新建未发布活动 |
| `1` | 已发布 | 可被用户端浏览和报名 |
| `2` | 已结束 | 活动结束后状态 |
| `3` | 已下架 | 暂停公开展示 |
| `4` | 已取消 | 活动取消，不再恢复 |

### 5.2 报名状态

字典类型：`vol_signup_status`

| 值 | 标签 | 用途 |
| --- | --- | --- |
| `0` | 待筛选 | 志愿者提交后等待管理员处理 |
| `1` | 通过 | 获得后续签到资格 |
| `2` | 拒绝 | 未通过筛选 |
| `3` | 候补 | 等待名额变化 |
| `4` | 取消 | 志愿者取消报名 |

## 6. 新增菜单权限

新增菜单仍挂在 `志愿管理` 目录下。

| 菜单ID | 名称 | 类型 | 路径或权限 |
| --- | --- | --- | --- |
| `2010` | 活动管理 | 菜单 | `voluntary/activity/index` |
| `2011` | 活动查询 | 按钮 | `manager:voluntary:activity:query` |
| `2012` | 活动新增 | 按钮 | `manager:voluntary:activity:add` |
| `2013` | 活动编辑 | 按钮 | `manager:voluntary:activity:edit` |
| `2020` | 报名管理 | 菜单 | `voluntary/signup/index` |
| `2021` | 报名查询 | 按钮 | `manager:voluntary:signup:query` |
| `2022` | 报名筛选 | 按钮 | `manager:voluntary:signup:review` |

`voluntary_admin` 角色已绑定 `2000-2004`、`2010-2013`、`2020-2022`，共 12 个志愿管理相关菜单权限。
