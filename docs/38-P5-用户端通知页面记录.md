## 3. 接入接口

接口前缀：`/app/voluntary/notifications`

| 接口 | 页面能力 |
| --- | --- |
| `GET /mine` | 我的通知分页列表 |
| `GET /unread-count` | 顶部铃铛和页面未读数 |
| `PUT /{id}/read` | 单条通知标记已读 |
| `PUT /read-all` | 全部通知标记已读 |

前端只允许跳转用户端内部路由：跳转地址必须以 `/` 开头，不能以 `//` 开头，且不能包含 `://`。

## 4. 页面能力

用户端 `/notifications` 已支持：

1. 顶部展示未读通知数、当前筛选数量和通知类型。
2. 按全部、未读、已读筛选。
3. 按通知类型筛选。
4. 列表展示通知类型、已读状态、标题、内容、创建时间、阅读时间、业务对象和业务编号。
5. 单条标记已读。
6. 全部标记已读。
7. 点击“查看”后跳转到通知配置的用户端内部路由。

Header 已支持：

1. 登录后查询未读数。
2. 路由切换后刷新未读数。
3. 通知页标记已读后通过 `voluntary-notification-updated` 事件刷新未读数。
4. 登录状态失效或退出后清空未读数。
5. 登录期间每 60 秒刷新一次未读数。
