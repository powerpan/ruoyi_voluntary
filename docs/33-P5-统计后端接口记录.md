## 3. 查询参数

| 参数 | 说明 |
| --- | --- |
| `beginDate` | 统计开始日期，格式 `yyyy-MM-dd` |
| `endDate` | 统计结束日期，格式 `yyyy-MM-dd` |
| `activityId` | 活动 ID |
| `activityTitle` | 活动标题模糊查询 |
| `organization` | 志愿者组织模糊查询 |
| `volunteerRealName` | 志愿者姓名模糊查询 |
| `trendType` | 趋势类型，`day` 或 `month`，默认 `day` |

参数规则：

1. `beginDate` 不能晚于 `endDate`。
2. `trendType` 不是 `month` 时按 `day` 处理。
3. 日期范围在不同统计口径中使用对应业务时间字段，不新增统计缓存表。

## 5. 统计口径

| 指标 | 口径 |
| --- | --- |
| 志愿者总数 | `vol_volunteer_profile` |
| 审核通过志愿者数 | `vol_volunteer_profile.audit_status = 1` |
| 活动总数 | `vol_activity` |
| 已发布活动数 | `vol_activity.status = 1` |
| 报名总数 | `vol_activity_signup` |
| 已通过报名数 | `vol_activity_signup.status = 1` |
| 签到记录数 | `vol_checkin_record.checkin_time is not null` |
| 签退记录数 | `vol_checkin_record.status = 1` |
| 有效服务记录数 | `vol_service_record.status = 1` |
| 有效服务分钟数 | `sum(vol_service_record.service_minutes) where status = 1` |
| 异常记录数 | `vol_service_record.status = 2` 加 `vol_checkin_record.status = 2` |

日期过滤规则：

1. 志愿者统计使用 `vol_volunteer_profile.create_time`。
2. 活动统计使用 `vol_activity.start_time`。
3. 报名统计使用 `vol_activity_signup.create_time`。
4. 签到签退统计使用 `vol_checkin_record.checkin_time`。
5. 服务时长统计使用 `vol_service_record.service_date`。
