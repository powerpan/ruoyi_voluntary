# P4-F 管理端页面记录

## 1. 本阶段目标

P4-F 的目标是在 P4-C、P4-D、P4-E 已完成接口基础上，补齐后台管理端的签到管理和服务记录页面，使管理员可以通过页面完成二维码生成、签到签退记录查询和服务记录查询。

本阶段只实现：

1. 管理端签到管理页面。
2. 管理端服务记录页面。
3. 签到管理页接入二维码 token 生成、查询和停用接口。
4. 签到管理页接入签到签退记录列表和详情接口。
5. 服务记录页接入服务记录列表和详情接口。

本阶段不实现用户端扫码结果页、用户端服务记录页、统计图表、通知中心、导出、人工补签或异常集中处理。

## 3. 页面功能

### 3.1 签到管理页

访问路径：

```text
/voluntary/checkin
```

页面能力：

1. 按活动标题、志愿者姓名、手机号、签到状态和创建时间查询签到签退记录。
2. 展示活动地点、志愿者联系方式、活动时间、签到时间、签退时间、签到方式和签退状态。
3. 查看单条签到签退记录详情。
4. 选择已发布活动后生成签到二维码或签退二维码。
5. 查看指定活动最近生成的二维码 token。
6. 停用仍处于有效状态的二维码 token。
7. 复制二维码扫码地址，地址格式为 `http://localhost:8088/#/scan?token=<token>`。

### 3.2 服务记录页

访问路径：

```text
/voluntary/serviceRecord
```

页面能力：

1. 按活动标题、志愿者姓名、手机号、服务记录状态和服务日期查询记录。
2. 展示活动地点、志愿者联系方式、服务日期、计入时间、服务分钟数、记录状态和生成时间。
3. 查看服务记录详情，包括签到记录 ID、报名 ID、确认人、确认时间、修正原因和备注。
