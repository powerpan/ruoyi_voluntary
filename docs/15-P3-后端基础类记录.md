## 3. 活动基础类

实体：`VolActivity`

对应表：`vol_activity`

主要字段：

| 字段 | 说明 |
| --- | --- |
| `title` | 活动标题 |
| `activityType` | 活动类型 |
| `serviceLocation` | 服务地点 |
| `startTime`、`endTime` | 活动开始和结束时间 |
| `signupStartTime`、`signupEndTime` | 报名开始和截止时间 |
| `recruitCount` | 招募人数 |
| `approvedCount` | 已通过报名人数 |
| `content` | 活动内容 |
| `requirements` | 报名要求 |
| `status` | 活动状态 |
| `publishTime` | 发布时间 |

为后续列表查询预留了两个非表字段：

| 字段 | 说明 |
| --- | --- |
| `keyword` | 标题和服务地点综合检索 |
| `signupOpen` | 是否只查询报名开放中的活动 |

Mapper 已支持：

1. 根据 ID 查询活动。
2. 按标题、关键字、类型、地点、状态、活动开始时间范围查询列表。
3. 按报名开放时间过滤活动。
4. 新增活动。
5. 更新活动。
6. 按 ID 或 ID 数组删除活动。

Service 已处理：

1. 新增活动时默认 `status=0` 草稿。
2. 新增活动时默认 `approvedCount=0`。
3. 新增和更新时维护 `createTime`、`updateTime`。

## 4. 报名基础类

实体：`VolActivitySignup`

对应表：`vol_activity_signup`

主要字段：

| 字段 | 说明 |
| --- | --- |
| `activityId` | 活动 ID |
| `volunteerUserId` | 志愿者用户 ID |
| `realName`、`phone`、`organization` | 报名时的志愿者资料快照 |
| `applyReason` | 报名理由 |
| `experience` | 相关经验 |
| `status` | 报名状态 |
| `reviewReason` | 筛选意见 |
| `reviewerId`、`reviewerName` | 处理人信息 |
| `reviewTime` | 处理时间 |

为后续管理端和用户端列表展示预留了活动关联字段：

| 字段 | 说明 |
| --- | --- |
| `activityTitle` | 活动标题 |
| `activityType` | 活动类型 |
| `serviceLocation` | 服务地点 |
| `activityStartTime`、`activityEndTime` | 活动时间 |
| `activityStatus` | 活动状态 |

Mapper 已支持：

1. 根据报名 ID 查询。
2. 根据活动 ID 和志愿者用户 ID 查询唯一报名记录。
3. 按活动、志愿者、姓名、电话、组织、状态、活动标题、活动类型和报名时间范围查询列表。
4. 统计活动已通过报名数。
5. 新增报名。
6. 更新报名。
7. 按 ID 或 ID 数组删除报名。

Service 已处理：

1. 新增报名时默认 `status=0` 待筛选。
2. 新增和更新时维护 `createTime`、`updateTime`。
