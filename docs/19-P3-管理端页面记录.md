## 3. 活动管理页面

页面路径：

```text
/voluntary/activity
```

页面能力：

| 能力 | 说明 |
| --- | --- |
| 列表查询 | 按关键字、活动类型、活动状态、报名中筛选 |
| 新增活动 | 创建草稿活动，填写活动时间、报名时间、招募人数等字段 |
| 编辑活动 | 编辑草稿或已下架活动 |
| 活动详情 | 查看活动基础信息、报名时间、招募人数、负责人和内容 |
| 发布活动 | 将草稿或已下架活动发布 |
| 下架活动 | 下架已发布活动 |
| 结束活动 | 手动结束已发布活动 |
| 取消活动 | 取消草稿、已发布或已下架活动 |

页面使用权限：

```text
manager:voluntary:activity:list
manager:voluntary:activity:query
manager:voluntary:activity:add
manager:voluntary:activity:edit
```

## 4. 报名管理页面

页面路径：

```text
/voluntary/signup
```

页面能力：

| 能力 | 说明 |
| --- | --- |
| 列表查询 | 按活动标题、志愿者姓名、手机、活动类型、报名状态筛选 |
| 报名详情 | 查看活动、志愿者、报名理由、相关经验和筛选意见 |
| 通过报名 | 将待筛选或候补报名处理为通过 |
| 拒绝报名 | 将待筛选或候补报名处理为拒绝，页面要求填写原因 |
| 候补报名 | 将待筛选报名处理为候补 |

页面使用权限：

```text
manager:voluntary:signup:list
manager:voluntary:signup:query
manager:voluntary:signup:review
```
