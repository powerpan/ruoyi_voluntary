# P3-G 用户端活动报名页面记录

## 1. 本次目标

P3-G 的目标是把用户端活动相关占位页接入 P3-D 已完成的真实接口，形成志愿者侧“活动浏览、活动详情、提交报名、查看我的报名、取消报名”的页面闭环。

本次仍严格限定在 P3 活动与报名范围内，不提前实现二维码签到签退、服务记录生成和服务时长统计。

## 3. 用户端活动列表

`Activities.vue` 已由占位页改为真实活动列表页，接入：

```text
GET /app/voluntary/activities
```

页面能力：

1. 展示已发布活动卡片。
2. 支持按标题或地点关键字搜索。
3. 支持按活动类型筛选。
4. 支持只看报名中的活动。
5. 展示活动地点、活动时间、报名截止时间、招募人数和已通过人数。
6. 点击“查看详情”进入活动详情页。
7. 点击“报名”进入详情页并带上报名意图。

未登录用户仍可浏览列表，这是 P3 接口设计中的公开访问能力。

## 4. 用户端活动详情与报名

`ActivityDetail.vue` 接入：

```text
GET  /app/voluntary/activities/{id}
GET  /app/voluntary/profile/audit-status
GET  /app/voluntary/signups/mine
POST /app/voluntary/activities/{id}/signups
```

页面能力：

1. 展示活动标题、类型、地点、时间、服务对象、活动内容、报名要求、负责人和服务时长上限。
2. 未登录用户显示“登录后报名”，点击后跳转登录页并保留当前详情页作为回跳目标。
3. 已登录但档案未审核通过的用户显示提示，引导进入个人中心查看审核状态。
4. 审核通过且在报名时间内、名额未满、没有有效报名记录的用户可打开报名弹窗。
5. 报名弹窗填写报名理由和相关经验，提交后写入 `vol_activity_signup`。
6. 已提交报名后，详情页展示“我的报名状态”和处理意见。

## 5. 我的报名

`Signups.vue` 接入：

```text
GET  /app/voluntary/signups/mine
POST /app/voluntary/signups/{id}/cancel
```

页面能力：

1. 展示当前登录志愿者自己的报名记录。
2. 支持按活动名称和报名状态筛选。
3. 展示活动类型、地点、活动时间、报名时间、报名理由、相关经验和处理意见。
4. 待筛选、通过、候补状态允许用户取消报名。
5. 已拒绝或已取消的报名不可再次取消。
6. 点击“查看活动”可回到活动详情页。
