# P2 阶段验收记录

## 1. 验收目标

本次验收范围是 P2-G：确认“志愿者账号与档案”阶段已经形成可运行闭环，并补齐用户端首页审核状态提示。

P2 收口后的能力包括：

1. 志愿者注册后自动创建待审核档案。
2. 志愿者登录后可维护个人资料。
3. 用户端个人中心和首页均可展示审核状态。
4. 管理员可查询、编辑、审核、驳回、禁用和启用志愿者。
5. 审核动作写入审核记录。
6. 审核状态接口可供 P3 报名资格校验复用。

本次仍不进入 P3 的活动、报名、筛选和签到业务实现。

## 2. 本次前端补充

改造文件：

```text
voluntary-app/src/views/Home.vue
voluntary-app/src/api/voluntary/profile.js
```

首页新增审核状态提示：

| 用户状态 | 首页展示 |
| --- | --- |
| 未登录 | 提示登录后查看审核状态，并提供登录、注册入口 |

## 6. P2 验收结论

P2 已完成。当前已证明以下验收场景成立：

1. 新用户可以注册并登录。
2. 注册成功后 `sys_user` 和 `vol_volunteer_profile` 同时存在。
3. 新志愿者默认状态为待审核。
4. 用户端个人中心能查看并维护志愿者档案。
5. 用户端首页能展示审核状态和审核意见。
6. 管理员能在志愿者审核页和接口中看到待审核用户。
7. 管理员通过审核后，志愿者状态变为通过。
8. 每次审核或状态变更都会写入 `vol_audit_record`。
9. 审核状态接口可供 P3 报名接口复用。

P2 不再继续扩展通知中心、活动报名或服务时长明细；这些内容分别进入 P3、P4 和 P5。
