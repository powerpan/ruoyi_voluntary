# P1 工程骨架迁移记录

## 1. 目标

P1 的目标是把参考项目的 RuoYi 工程底座迁移到当前仓库，并改造成志愿活动管理系统的基础骨架。此阶段不实现志愿者审核、活动管理、报名、签到签退和服务时长统计等业务。

## 2. 参考来源

参考项目：

```bash
/Users/ericpan/game_project/ruoyi_pet_adopt
```

复用范围：

1. RuoYi 后端基础模块。
2. 管理端 Vue 基础结构。
3. 用户端 Vue 基础结构。
4. 启动脚本、部署目录和 SQL 初始化脚本的组织方式。

未复用范围：

1. 宠物档案、领养发布、领养申请、领养回访等旧业务模块。
2. 参考项目中的宠物业务菜单、接口和页面。
3. 与志愿活动无关的业务表和演示数据。
