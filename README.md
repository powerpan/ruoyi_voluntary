## 项目目标

系统面向校园、社区或公益组织的志愿活动管理场景，核心目标是形成一个完整、可演示、可维护的业务闭环：

1. 志愿者注册、登录、维护个人信息。
2. 管理员审核和管理志愿者档案。
3. 管理员创建、发布、编辑、下架志愿活动。
4. 志愿者浏览活动并报名参与。
5. 管理员筛选报名人员。
6. 志愿者通过二维码完成签到和签退。
7. 系统自动生成服务记录并统计服务时长。
8. 管理员按活动、志愿者、组织和时间范围查看统计数据。

## 参考项目

参考项目路径：

```bash
/Users/ericpan/game_project/ruoyi_pet_adopt
```

该项目是基于 RuoYi + Vue 的课程项目版宠物领养平台。它的工程结构、后台权限、用户端页面、业务模块拆分、SQL 初始化脚本、启动脚本和部署目录都可以作为本项目的工程基础。

复用原则：

- 复用工程骨架，不直接保留宠物业务语义。
- 复用用户端和管理端分离的接口结构。
- 复用审核记录、通知中心、后台菜单权限和统计页面模式。
- 不复用宠物档案、领养沟通、回访等与志愿活动无关的业务。
- 二维码签到签退、服务时长统计、志愿者审核规则需要重新设计和实现。
